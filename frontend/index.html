โปรแกรม CropWat 8.0

ถ้าติดตั้งไว้ที่ตำแหน่งมาตรฐาน ระบบจะหาให้เอง ไม่ต้องตั้งค่า
กำลังตรวจสอบ...
ระบุตำแหน่งโปรแกรมเอง
ใช้เมื่อติดตั้ง CropWat ไว้นอกตำแหน่งมาตรฐาน — ชี้ไปที่ไฟล์ CROPWAT.exe แล้วกดบันทึก

ตัวเลือกการทำงาน

ขั้นสูง: กำหนดสถานี/ไฟล์เอง
เว้นว่างไว้ได้ — ระบุเฉพาะเมื่อตรวจสอบแล้วพบมากกว่า 1 ตัวเลือก
การตั้งค่าเป็นปัจจุบัน

เริ่มต้นใช้งาน

  1. เตรียมข้อมูลไว้ในโฟลเดอร์เดียว
    ระบบอ่านปี+เดือนจากชื่อไฟล์ ชื่อต้องตรงรูปแบบ (ไม่แยกตัวพิมพ์ใหญ่-เล็ก):
    • โฟลเดอร์สถานี: Clim_425201, Rain_450006
    • climate: 425201clim_1981apr.PED
    • rain: Rain_450006_1981Apr.CRD
    • พืช/ดิน: ชื่อใดก็ได้ นามสกุล .CRO / .SOI
  2. แท็บ "ตั้งค่า" — ทำ 3 ขั้น
    1) เลือกโฟลเดอร์ข้อมูลแล้วกด ตรวจสอบ → 2) เลือกโฟลเดอร์ผลลัพธ์ → 3) ดูว่าพบโปรแกรม CropWat แล้ว → กด บันทึกการตั้งค่า (ทำครั้งเดียว) — ไม่ต้องเปิด CropWat ไว้เอง
  3. แท็บ "ภาพรวม"
    ใส่ช่วงปี ตรวจแผนวันปลูก → กด เริ่มประมวลผล (หรือ Ctrl+Alt+F9, หยุด Ctrl+Alt+F10) — แผงด้านบนบอกว่าถึงไหนแล้วและเหลืออีกนานเท่าไร ระหว่างรันใช้เครื่องทำอย่างอื่นได้
  4. รับผลลัพธ์
    เสร็จแล้วได้ Result.xlsx และ Screenshots.docx อัตโนมัติ กด เปิด Excel เพื่อดูผล — sheet สรุป บอกวันปลูกที่ดีที่สุด, หมายเหตุ บอกปีที่มีปัญหา
