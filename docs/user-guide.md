## 1. สิ่งที่ต้องมีก่อนเริ่ม

| รายการ | รายละเอียด |
|---|---|
| Windows 10 หรือ 11 | โปรแกรมทำงานบน Windows เท่านั้น (ควบคุม CropWat ผ่านกลไกของ Windows โดยตรง) |
| CropWat 8.0 | โปรแกรมของ FAO ตัวจริง ติดตั้งไว้ในเครื่องก่อน — ดาวน์โหลดได้จาก [เว็บไซต์ FAO](https://www.fao.org/land-water/databases-and-software/cropwat/en/) (CropWat Auto-runner ทำหน้าที่ "ควบคุม" CropWat ให้ ไม่ได้แทนที่มัน) |
| ไฟล์ข้อมูล | climate / rain / crop / soil ที่จะใช้ประมวลผล (กติกาตั้งชื่อไฟล์อยู่ข้อ 4) |

> **คำแนะนำ:** ตอนติดตั้ง CropWat 8.0 ให้กด Next ตามค่าเริ่มต้นของตัวติดตั้งไป
> เรื่อยๆ (อย่าเปลี่ยนโฟลเดอร์ติดตั้ง) แล้วข้อ 3 ด้านล่างจะ "ไม่ต้องทำอะไรเลย"

## 2. ติดตั้งและเปิดโปรแกรมครั้งแรก

1. ดาวน์โหลด `CropWatAutoRunner.exe` เวอร์ชันล่าสุดจากหน้า [Releases](../../releases)
   — เป็นไฟล์เดียวจบ **ไม่ต้องติดตั้ง** วางไว้ที่ไหนก็ได้ (แนะนำสร้างโฟลเดอร์
   ของมันเอง เพราะโปรแกรมจะเขียนไฟล์ log ไว้ข้างๆ ตัว .exe)
2. ดับเบิลคลิกเปิด — ถ้า Windows ขึ้นเตือน **"Windows protected your PC"**
   (SmartScreen) ให้กด **More info** แล้วกด **Run anyway** (ขึ้นเพราะไฟล์ไม่ได้
   ซื้อใบรับรองลงนามโค้ด ไม่ได้แปลว่ามีไวรัส)
3. หน้าต่างโปรแกรมจะเปิดขึ้นมาเอง พร้อมไอคอนโปรแกรมที่**ถาดระบบ (System Tray)**
   มุมล่างขวาของจอ — ไอคอนนี้คือสัญญาณว่าโปรแกรมทำงานอยู่ ปิดหน้าต่างไปโปรแกรม
   ก็ยังทำงานต่อเบื้องหลัง (ปิดโปรแกรมจริงๆ ให้คลิกขวาที่ไอคอน → "ปิดโปรแกรม")
4. เปิดครั้งแรกจะมี**คู่มือเริ่มต้นใช้งาน**เด้งขึ้นมาสรุปขั้นตอนทั้งหมด — เรียกดู
   ซ้ำได้ตลอดจากปุ่ม **?** (คู่มือ) มุมขวาบน
5. ค่าเริ่มต้นเป็นธีมมืด — กดปุ่มรูปพระจันทร์/ดวงอาทิตย์มุมขวาบนเพื่อสลับ มืด → สว่าง → ตามระบบ (Windows)
   โปรแกรมจำค่าที่เลือกไว้ให้

## 3. ต้องตั้งตำแหน่ง (path) โปรแกรม CropWat เองไหม?

**คำตอบสั้น: ส่วนใหญ่ไม่ต้อง** — ระบบค้นหาให้อัตโนมัติ

| สถานการณ์ | ต้องทำอะไร |
|---|---|
| ติดตั้ง CropWat 8.0 แบบมาตรฐาน (กด Next ตามตัวติดตั้ง) | **ไม่ต้องทำอะไรเลย** เว้นช่องว่างไว้ได้ ระบบหาเจอเองที่ `C:\Program Files (x86)\CROPWAT\cropwat.exe` |
| ติดตั้งไว้โฟลเดอร์อื่น / ไดรฟ์อื่น | ไปที่แท็บ **ตั้งค่า** → **ขั้นที่ 3 "โปรแกรม CropWat 8.0"** → กด **ระบุตำแหน่งโปรแกรมเอง** → **เลือกไฟล์...** แล้วชี้ไปที่ `CROPWAT.exe` ของคุณ → **บันทึกการตั้งค่า** |
| ไม่แน่ใจว่าติดตั้งแบบไหน | ดูที่ขั้นที่ 3 "โปรแกรม CropWat 8.0" ในแท็บตั้งค่า — มีกล่องสถานะบอกชัดเจน (ดูด้านล่าง) |

**วิธีเช็คว่าระบบหาเจอหรือยัง:** เปิดแท็บ **ตั้งค่า** → ดูกล่องสถานะในขั้นที่ 3
"โปรแกรม CropWat 8.0" (ตอนยังตั้งค่าไม่ครบ ดูได้จากเช็คลิสต์ข้อ 3 บนหน้าภาพรวมด้วย):

- ✓ สีเขียว **"พบโปรแกรมอัตโนมัติ: C:\Program Files (x86)\CROPWAT\cropwat.exe
  — ไม่ต้องตั้งค่าเพิ่ม"** → พร้อมใช้งาน จบ ไม่ต้องแตะอะไร
- ✓ สีเขียว **"ใช้ไฟล์ที่ระบุ: ..."** → ใช้ path ที่คุณตั้งเอง พร้อมใช้งาน
- ✗ สีแดง **"ไม่พบ CropWat 8.0 ในเครื่อง"** → ยังใช้งานไม่ได้ ต้องติดตั้ง CropWat ก่อน
  หรือถ้าติดตั้งแล้ว ช่อง **ระบุตำแหน่งโปรแกรมเอง** จะกางออกให้เอง กด **เลือกไฟล์...**
  ชี้ตำแหน่งแล้วบันทึก

**หาไฟล์ CROPWAT.exe ของตัวเองไม่เจอ?** คลิกขวาที่ไอคอน CropWat 8.0 บน
Desktop/Start Menu → **Open file location** จะพาไปที่โฟลเดอร์ที่มีไฟล์ .exe อยู่

## 4. เตรียมไฟล์ข้อมูล — กติกาตั้งชื่อ (สำคัญมาก)

ระบบอ่าน "ปี + เดือน" จาก**ชื่อไฟล์โดยตรง** ชื่อไม่ตรงกติกา = ตรวจสอบไม่พบ
(ตัวพิมพ์ใหญ่/เล็กไม่มีผล จะซ้อนโฟลเดอร์ย่อยกี่ชั้นก็ได้):

| ประเภท | กติกา | ตัวอย่างที่ถูก |
|---|---|---|
| โฟลเดอร์สถานี | ขึ้นต้น `Clim_` หรือ `Rain_` | `Clim_425201`, `Rain_450006` |
| ไฟล์ climate | `{รหัสสถานี}clim_{ปี}{เดือน3ตัว}.PED` | `425201clim_1981apr.PED` |
| ไฟล์ rain | `rain_{รหัสสถานี}_{ปี}{เดือน3ตัว}.CRD` | `Rain_450006_1981Apr.CRD` |
| ไฟล์พืช (crop) | นามสกุล `.CRO` ชื่ออะไรก็ได้ | `MAIZE.CRO` |
| ไฟล์ดิน (soil) | นามสกุล `.SOI` ชื่ออะไรก็ได้ | `SANDYLOAM.SOI` |

- เดือน 3 ตัว = `jan feb mar apr may jun jul aug sep oct nov dec`
- รวมทุกอย่าง (โฟลเดอร์สถานี + ไฟล์พืช + ไฟล์ดิน) ไว้ใน**โฟลเดอร์ใหญ่โฟลเดอร์เดียว**
  แล้วชี้โปรแกรมไปที่โฟลเดอร์นั้นโฟลเดอร์เดียวพอ — ระบบสแกนลึกลงไปเอง

**ตัวอย่างโครงสร้างที่ใช้ได้:**

```
ข้อมูลของฉัน/                      ← ชี้โปรแกรมมาที่นี่
  Clim_425201/
    425201clim_1981apr.PED
    425201clim_1981may.PED
    ...
  Rain_450006/
    Rain_450006_1981Apr.CRD
    ...
  MAIZE.CRO
  SANDYLOAM.SOI
```

## 5. ตั้งค่าครั้งแรก (แท็บ "ตั้งค่า")

ทำครั้งเดียว ระบบจดจำถาวรแม้ปิดโปรแกรม — ตอนยังตั้งค่าไม่ครบ หน้า **ภาพรวม** จะมีแถบ
**"เริ่มต้นใช้งาน"** บอกว่ายังขาดขั้นไหน พร้อมปุ่ม **ไปที่หน้าตั้งค่า**

หน้าตั้งค่าเรียงเป็น 3 ขั้น (ขั้นที่เสร็จแล้ว วงกลมตัวเลขจะเปลี่ยนเป็น ✓ สีเขียว):

1. **ขั้นที่ 1 — โฟลเดอร์ข้อมูลต้นทาง:** กด **เลือกโฟลเดอร์...** ชี้ไปที่โฟลเดอร์ใหญ่จากข้อ 4
   แล้วกด **ตรวจสอบ** — ต้องเห็นรายการสถานี/ไฟล์ครบตามที่คาด ถ้าไม่ครบให้กลับไป
   เช็คชื่อไฟล์ตามกติกาข้อ 4
2. **ขั้นที่ 2 — โฟลเดอร์ผลลัพธ์:** กด **เลือกโฟลเดอร์...** ชี้ไปที่โฟลเดอร์เปล่าที่จะเก็บ
   ผลลัพธ์ทั้งหมด (ระบบสร้างโครงสร้างข้างในให้เอง)
3. **ขั้นที่ 3 — โปรแกรม CropWat 8.0:** ดูกล่องสถานะ — ถ้าขึ้น ✓ สีเขียวอยู่แล้ว ข้ามไปได้เลย
   (ส่วนใหญ่จะเป็นแบบนี้ ดูข้อ 3)
4. การ์ด **"ตัวเลือกการทำงาน"** แนะนำให้คงค่าเริ่มต้นไว้ทั้งหมด (รันบนเดสก์ท็อปเบื้องหลัง = เปิด,
   สร้าง Excel และ Word อัตโนมัติ = เปิด, ใช้ไฟล์ climate/rain ตามเดือนปลูก = เปิด,
   ความเร็ว = ปกติ)
5. กด **บันทึกการตั้งค่า** ที่แถบด้านล่าง — ถ้าแก้ค่าแล้วยังไม่ได้บันทึก แถบจะเป็นสีส้ม
   ขึ้นว่า "มีการแก้ไขที่ยังไม่ได้บันทึก" และมีจุดสีส้มบนแท็บ "ตั้งค่า"

> **เครื่องรุ่นเก่า/ช้า:** ถ้าเจอ CropWat ไม่ตอบสนองระหว่างประมวลผลบ่อยๆ ให้เปลี่ยน
> "ความเร็ว" (การ์ด "ตัวเลือกการทำงาน") เป็น **ช้า** แล้วบันทึก จากนั้นเริ่มประมวลผลใหม่

### อยากให้เสร็จไวขึ้น — รันหลายหน้าต่างพร้อมกัน

โปรแกรมเปิด CropWat หลายหน้าต่าง (มองไม่เห็นบนจอ) แบ่งกันทำคนละปีให้เอง — **ค่าเริ่มต้นคือ
"อัตโนมัติ"**: ทุกครั้งที่กดเริ่มประมวลผล โปรแกรมตรวจกำลังเครื่อง (จำนวน CPU, แรมที่ว่าง,
เครื่องกำลังทำงานอื่นหนักแค่ไหน) แล้วเลือกจำนวนหน้าต่างให้ 1–4 หน้าต่าง ไม่ต้องตั้งอะไรเลย

**ปรับระหว่างรันได้ทันที:** ตอนกำลังประมวลผล ข้างปุ่ม **หยุด** มีแถบ **"หน้าต่าง CropWat [−] 3 [+]"**
- จะใช้คอมทำงานอื่นไปด้วย (เครื่องอืด) → กด **−** ลดลง หน้าต่างที่เกินจะปิดหลังวันปลูกที่ทำอยู่
  เสร็จ (ไม่กี่วินาที) วันปลูกที่เหลือของปีนั้นย้ายไปให้หน้าต่างอื่นทำต่อ — **งานไม่หาย ไม่ทำซ้ำ**
- เลิกใช้เครื่องแล้ว อยากให้เสร็จไว → กด **+** เพิ่มกลับ
- ค่าที่ปรับตรงนี้ใช้เฉพาะรอบที่รันอยู่ รอบหน้ากลับไปใช้ค่าในหน้าตั้งค่า

**ตั้งเองถาวร:** แท็บตั้งค่า → การ์ด **"ตัวเลือกการทำงาน"** → **"จำนวนหน้าต่าง CropWat พร้อมกัน"**
เลือก อัตโนมัติ / 1 / 2 / 3 / 4 แล้วกด **บันทึกการตั้งค่า** (ใต้ช่องนี้บอกด้วยว่าเครื่องนี้
โหมดอัตโนมัติจะใช้กี่หน้าต่าง และเพราะอะไร)

- ผลลัพธ์ **เหมือนกับรันทีละหน้าต่างทุกตัวเลข** — ขั้นตอนใน CropWat เหมือนเดิมทุกอย่าง
- ระหว่างรัน หัวการ์ดบอกว่ากำลังคำนวณปีไหนบ้าง เช่น "กำลังคำนวณปี 1990, 1991, 1992 พร้อมกัน"
- ใช้ได้เฉพาะเมื่อเปิด **"รันบนเดสก์ท็อปเบื้องหลัง"** (โหมดที่ CropWat ทำงานบนจอจริงใช้ได้แค่
  1 หน้าต่าง)
- ถ้าเจอ CropWat ค้าง/วันปลูกตกบ่อยขึ้นตอนใช้หลายหน้าต่าง ให้กด − ลดลง หรือตั้ง 1–2 ถาวร
- กด **หยุด** หรือ **Force Close** แล้วระบบปิด CropWat ทุกหน้าต่างให้เอง

### ตั้งค่า CropWat (Options) จากในโปรแกรม

การ์ด **"ค่าตั้งของ CropWat (Options)"** ในแท็บตั้งค่า แทนหน้า Settings → Options ของ
CropWat ได้ทั้งหมด (แบ่งแท็บเหมือนกัน: Effective rainfall / Non-rice crop scheduling /
Rice scheduling / Land preparation (rice) / Climate / ETo) — ช่องที่เกี่ยวข้องจะโผล่เอง
ตามตัวเลือก เช่นเลือก "Irrigate at fixed interval per stage" แล้วจะมีช่องจำนวนวันของแต่ละระยะ

1. เลือกแท็บและแก้ค่า — ช่องที่แก้จะเป็นสีส้ม และป้ายมุมขวาบนขึ้นว่า "ยังไม่บันทึก"
2. กด **บันทึกค่าลง CropWat** — เท่ากับกด "Save as default" ใน CropWat (เขียนไฟล์
   `C:\ProgramData\CROPWAT\Cropwat.ini` ของเครื่องนี้) มีผลกับ CropWat ทุกครั้งที่เปิดใหม่
   ทั้งตัวที่โปรแกรมนี้เปิดเองและตัวที่คุณเปิดเอง
3. แก้ผิด? กด **ย้อนกลับค่าก่อนบันทึกล่าสุด** (กดซ้ำเพื่อสลับกลับได้)

ข้อควรรู้:
- **แก้ระหว่างกำลังประมวลผลไม่ได้** (ผลชุดเดียวกันต้องใช้ค่าเดียวกันทั้งชุด) — หยุดหรือรอให้เสร็จก่อน
- ถ้ามี CropWat เปิดค้างอยู่ ตัวนั้นจะยังใช้ค่าเดิมจนกว่าจะปิดแล้วเปิดใหม่ และ**อย่ากด
  Save as default ใน CropWat ตัวนั้น** ไม่งั้นจะทับค่าที่ตั้งจากโปรแกรมนี้
- ตัวเลือก "user defined" (ตารางช่วงให้น้ำ/ความลึกที่กำหนดเอง) เลือกได้ แต่ตารางต้องกรอกในโปรแกรม CropWat เอง
- **ใช้หลายเครื่อง:** ค่านี้เก็บแยกในแต่ละเครื่อง — กด **ส่งออกโปรไฟล์...** แล้วนำไฟล์ไป
  **นำเข้าโปรไฟล์...** ที่เครื่องอื่น ผลจะได้คำนวณด้วยค่าเดียวกัน
- ก่อนเริ่มประมวลผล ดูได้ที่การ์ด "แผนวันปลูก" ว่ารอบนี้จะใช้ค่าอะไร — และทุกครั้งที่เริ่ม
  ระบบเก็บสำเนาไว้ที่โฟลเดอร์ผลลัพธ์ (`CropWat_Options_used.ini`) พร้อมลงค่าหลักไว้ใน
  sheet "หมายเหตุ" ของ Result.xlsx ให้รู้ย้อนหลังว่าผลชุดนั้นคำนวณด้วยค่าอะไร

## 6. เลือกช่วงปีและวันปลูก (แผนวันปลูก)

ที่แท็บ **ภาพรวม** — ช่วงปีอยู่ในแผงสถานะด้านบนสุด ส่วนวันปลูกอยู่ในการ์ด **"แผนวันปลูก"**:

1. ใส่ **ปีเริ่มต้น** และ **ปีสิ้นสุด** ที่ต้องการทดสอบ (เช่น 1981 – 2025)
2. **ตั้งพร้อมกันทุกเดือน** (แถบบนสุดของการ์ด): **ตั้งวันปลูกทุกเดือน** (1, 15 / ทุก 7 วัน /
   ทุกวัน / ข้ามทุกเดือน) และ **ถ่ายภาพทุกเดือน** (1, 15 / ทั้งหมด / ไม่มี) — ใช้กับเดือนที่
   ไม่ได้ติ๊ก "ข้าม" เท่านั้น (ถ้าข้ามอยู่ทุกเดือน จะใช้กับทั้ง 12 เดือน) และจะถามยืนยันก่อน
   เขียนทับเดือนที่เลือกวันเองไว้ หรือก่อนข้ามทุกเดือน
3. **ปรับรายเดือน:** แต่ละเดือนเป็น 1 แถว มีปุ่มลัด **ทุกวัน / ทุก 7 วัน / 1, 15 / กำหนดเอง**
   (กด **กำหนดเอง** = เปิดตารางรายวันให้คลิกเลือกเอง กดซ้ำเพื่อพับเก็บ)
4. เดือนไหนไม่ต้องการทดสอบ ติ๊ก **ข้าม** ท้ายแถวของเดือนนั้น
5. ชิป **ถ่ายภาพ** ของแต่ละเดือน (ไม่มี / ทั้งหมด / 1, 15) = เลือกว่าวันไหนให้บันทึกภาพหน้าจอ
   ผลลัพธ์ (Screenshot) เก็บไว้ประกอบรายงานด้วย — จุดสีทองบนตัวเลขวัน = วันที่จะบันทึกภาพ
6. แผนวันปลูก**บันทึกอัตโนมัติ**ทุกครั้งที่แก้ ไม่ต้องกดปุ่มบันทึก — หัวการ์ดสรุปจำนวน
   วันปลูก/ปี ภาพ/ปี และจำนวนเดือนไว้ให้เห็นแม้พับการ์ดเก็บ
7. ตัวเลข 4 ช่องในแผงสถานะด้านบนบอกจำนวนวันปลูก/ปี, รอบคำนวณทั้งหมด, ภาพบันทึก/ปี และ
   ชั่วโมงงานที่ประหยัดได้เทียบกับการทำมือ

## 7. เริ่มประมวลผลและติดตามงาน

1. กด **เริ่มประมวลผล** (หรือกด `Ctrl+Alt+F9` จากที่ใดก็ได้ในเครื่อง)
2. ก่อนเริ่มจริง ระบบ**ตรวจไฟล์ climate/rain ล่วงหน้าครบทุกวันปลูก** — ถ้าพบวันปลูก
   ที่ไม่มีไฟล์ให้ใช้ (เช่น สถานีเริ่มมีข้อมูลทีหลังเดือนที่เลือก) จะขึ้นกล่องแจ้ง
   รายละเอียดให้ยืนยันก่อน (วันปลูกที่มีปัญหาจะขึ้นสถานะ "มีปัญหา" ส่วนวันอื่น
   ดำเนินการตามปกติ)
3. ระบบจะ**เปิด CropWat ให้เองในเดสก์ท็อปแยกเบื้องหลัง** ที่มองไม่เห็นบนจอ —
   **ใช้เครื่องทำงานอื่นได้ตามปกติ** ระหว่างประมวลผล การคลิก/พิมพ์ใดๆ ไม่กระทบงาน
4. แผงสถานะด้านบนจะเปลี่ยนเป็น **"กำลังคำนวณปี ..."** พร้อมเปอร์เซ็นต์และเวลาที่เหลือ —
   การ์ดแผนวันปลูกจะพับเก็บให้เอง จะได้เห็นผลลัพธ์และภาพหน้าจอได้ทันที (กดเปิดดูได้
   ตลอด แก้แผนระหว่างรันได้แต่จะมีผลกับรอบถัดไป)

**สีของแผงสถานะ:** น้ำเงิน = พร้อมเริ่ม · ส้ม = กำลังประมวลผล หรือยังตั้งค่าไม่ครบ ·
เขียว = เสร็จครบแล้ว · แดง = มีปีที่มีปัญหา

**ติดตามความคืบหน้าได้ 4 ทาง:**

| ช่องทาง | รายละเอียด |
|---|---|
| การ์ด "ภาพหน้าจอ CropWat" | แสดงภาพการทำงานจริงโดยอัตโนมัติทุกครั้งที่ระบบบันทึกภาพ — กด **Snapshot** ดูภาพ ณ ตอนนี้ทันที หรือกด **Live View** ดูต่อเนื่อง (อัปเดตทุก ~2 วินาที; งานช้าลงเล็กน้อยระหว่างเปิด และหยุดเองเมื่องานเสร็จ) คลิกที่ภาพเพื่อขยาย |
| แถบความคืบหน้าลอย | มุมล่างขวาของจอ โผล่เองระหว่างประมวลผล ลากย้ายได้ กด 🗕 เพื่อซ่อน (เรียกคืน: คลิกขวาไอคอนถาดระบบ → "แสดงแถบความคืบหน้า") |
| ไอคอนถาดระบบ (System Tray) | เอาเมาส์ชี้ = เห็นปี/เปอร์เซ็นต์/เวลาที่เหลือ โดยไม่ต้องเปิดหน้าต่างใด — จุดเขียวบนไอคอน = กำลังทำงาน |
| หน้าต่างโปรแกรม | แผงสถานะด้านบน (ปีที่กำลังทำ เปอร์เซ็นต์ เวลาที่เหลือ) + ช่องสีรายปีในการ์ด "ผลลัพธ์" — กดปุ่ม **—** (ย่อหน้าต่าง) มุมขวาบนเพื่อพับเก็บ โปรแกรมทำงานต่อเบื้องหลัง (เปิดกลับ: ดับเบิลคลิกไอคอนถาดระบบ) |

- หยุดงาน: ปุ่ม **หยุด** หรือ `Ctrl+Alt+F10` — งานที่เสร็จแล้วไม่หาย
- **งานเสร็จมี notification เด้งแจ้งทันที** แม้กำลังทำงานอื่นอยู่
- **ทำต่อจากเดิมได้เสมอ:** กด "เริ่มประมวลผล" อีกครั้งเมื่อไรก็ได้ ระบบข้ามรายการ
  ที่เสร็จสมบูรณ์แล้วอัตโนมัติ — แผงสถานะจะขึ้นว่า **"พร้อมทำต่อจากเดิม"** (ดูจำนวนที่เสร็จได้
  จากบรรทัด "ไฟล์ผลลัพธ์สมบูรณ์" ในการ์ด "ผลลัพธ์" หน้าภาพรวม)

## 8. ไฟล์ผลลัพธ์

เมื่อประมวลผลจบ ระบบสร้างไฟล์ส่งงานให้**อัตโนมัติ** (ปิดได้ที่แท็บตั้งค่า) — สร้างให้
แม้บางปีจะมีปัญหา โดยปีที่มีปัญหาจะถูกบันทึกไว้ใน sheet "หมายเหตุ":

```
โฟลเดอร์ผลลัพธ์/
  txt/               ← ไฟล์ผลดิบจาก CropWat (รายวันปลูก)
  screenshots/       ← ภาพบันทึกหน้าจอ (เฉพาะวันที่เลือกถ่ายภาพไว้)
  _error_dialogs/    ← ภาพหน้าจอตอน CropWat แจ้ง error (มีเฉพาะเมื่อเกิดปัญหา)
  Result.xlsx        ← ตารางรวมผลทุกวันปลูก
  Screenshots.docx   ← เอกสารรวมภาพทั้งหมด
```

**ใน Result.xlsx มี 3 sheet:**

| Sheet | เนื้อหา |
|---|---|
| Result | ผลรายปี × วันปลูก ปีละ 11 แถว — แถว % yield reduction มีแถบสี (เขียว = ลดน้อย, แดง = ลดมาก) |
| สรุป | 1 แถวต่อวันปลูก: % yield reduction เฉลี่ย/ต่ำสุด/สูงสุดข้ามทุกปี + ค่าเฉลี่ยน้ำชลประทาน/การใช้น้ำ/ฝนใช้การได้ — **แถวสีเขียว = วันปลูกที่ผลผลิตลดเฉลี่ยน้อยที่สุด** |
| หมายเหตุ | สถานี/พืช/ดิน + บันทึกรายปี: วันปลูกที่มีผล/ที่ขาด ข้อความ error และชื่อภาพ error (แถวสีส้ม = ปีที่ต้องตรวจสอบ) |

> sheet อื่นที่คุณเพิ่มเองในไฟล์จะไม่ถูกแตะ — ถ้ามี sheet ชื่อ "สรุป" หรือ "หมายเหตุ"
> ที่คุณเขียนเองอยู่แล้ว ระบบจะไม่เขียนทับ แต่สร้าง "สรุป (auto)" / "หมายเหตุ (auto)" แทน
> ส่วน sheet ที่ระบบสร้างเองจะถูกสร้างใหม่ทุกครั้ง อย่าแก้ข้อมูลในนั้น

- ดูผลเร็วๆ: ปุ่ม **เปิด Excel** / **เปิด Word** ในการ์ด "ผลลัพธ์" — สร้างไฟล์ใหม่จากผล
  ล่าสุดแล้วเปิดให้ทันที (ถ้าไฟล์เปิดค้างอยู่ จะเปิดฉบับเดิมให้ ปิดไฟล์แล้วกดใหม่เพื่ออัปเดต)
  — พอประมวลผลเสร็จครบ แผงสถานะด้านบนจะเป็นสีเขียวพร้อมปุ่ม **เปิด Excel ดูผล** ให้กดได้เลย
- เปิดโฟลเดอร์: ปุ่ม **เปิดโฟลเดอร์** ในหน้าภาพรวม หรือคลิกขวาไอคอนถาดระบบ
  → "เปิดโฟลเดอร์ผลลัพธ์"
- โฟลเดอร์ `_peek_screenshots` (ถ้ามี) = ภาพจากปุ่ม Snapshot/Live View ใช้ตรวจสอบ
  เท่านั้น **ไม่เกี่ยวกับไฟล์ส่งงาน** ลบทิ้งได้เสมอ

## 9. ปัญหาที่พบบ่อย

**เริ่มประมวลผลแล้วขึ้นว่า "หาไฟล์โปรแกรม CropWat ไม่เจอ"**
ยังไม่ได้ติดตั้ง CropWat 8.0 หรือติดตั้งไว้นอกตำแหน่งมาตรฐาน — ดูข้อ 3
(ตั้ง path ที่ขั้นที่ 3 "โปรแกรม CropWat 8.0" ในแท็บตั้งค่า)

**กด "เริ่มประมวลผล" แล้วขึ้นกล่องเตือนว่าบางวันปลูก "ไม่มีไฟล์"**
สถานี climate/rain มีข้อมูลเริ่มทีหลังเดือนที่เลือกทดสอบ — ระบบจะไม่เดาใช้ข้อมูล
เดือนอื่นแทนเด็ดขาด (ผลจะเพี้ยน) เลือกเองว่าจะข้ามวันปลูกเหล่านั้นหรือเปลี่ยน
แผนการทดสอบ

**ตรวจสอบโฟลเดอร์ข้อมูลแล้วไม่เจอไฟล์ / เจอไม่ครบ**
เกือบทั้งหมดเกิดจากชื่อไฟล์ไม่ตรงกติกา — เทียบกับตารางในข้อ 4 ทีละส่วน
(โฟลเดอร์สถานีต้องขึ้นต้น `Clim_`/`Rain_` ด้วย)

**CropWat ไม่ตอบสนอง / ค้างระหว่างประมวลผล**
กดลิงก์ **CropWat ค้าง? Force Close** มุมขวาล่างของแผงสถานะในหน้าภาพรวม — บังคับปิด CropWat ทุกตัว + คืนสถานะระบบ
พร้อมเริ่มใหม่ทันที ข้อมูลที่เสร็จแล้วไม่หาย กด "เริ่มประมวลผล" ต่อจากเดิมได้เลย
(CropWat crash เองเป็นครั้งคราวจากบั๊กภายในของมัน เช่น "Access violation" —
ระบบเปิด CropWat ใหม่ให้เองทุกครั้งที่เริ่มงาน จึงฟื้นจากเหตุการณ์แบบนี้ได้ง่าย)
ถ้าเครื่องช้าและเจอบ่อย ให้ปรับ "ความเร็ว" (การ์ด "ตัวเลือกการทำงาน") เป็น **ช้า** ในแท็บตั้งค่า

**ขึ้น error "เจอหน้าต่าง...มากกว่า 1 หน้าต่าง"**
พบในเวอร์ชันก่อน v0.10.1 เมื่อโปรแกรมถูกปิดกลางคันระหว่างงาน (CropWat เก่าค้าง
อยู่เบื้องหลัง) — **อัปเดตเป็นเวอร์ชันล่าสุด** ระบบจะเก็บกวาดตัวค้างให้เอง
อัตโนมัติทุกครั้งก่อนเริ่ม (เวอร์ชันเก่า: กด Force Close หนึ่งครั้งแล้วเริ่มใหม่)

**บางปี/บางวันปลูกขึ้นสถานะ "มีปัญหา" — อยากรู้ว่า CropWat แจ้ง error อะไร**
ตั้งแต่ v0.11.0 เมื่อ CropWat เด้ง error ระหว่างประมวลผลเบื้องหลัง ระบบจะ**ถ่ายภาพ
เก็บให้อัตโนมัติ** — ตั้งแต่ v0.11.2 เป็นภาพ**หน้าต่าง CropWat ทั้งบาน**พร้อมกล่อง
error วางทับตรงกลาง (เห็นทั้งข้อความ error และข้อมูลที่โหลดอยู่ตอนนั้นในภาพเดียว) —
ปีที่มีปัญหาจะแสดงในกล่องสีแดงบนสุดของการ์ด "ผลลัพธ์" (หรือกดปุ่ม **ดูปีที่มีปัญหา**
ในแผงสถานะ) — กด **ดูภาพ** ท้ายข้อความ error เพื่อเปิดดูได้ว่า CropWat บ่นอะไร
และพังตอนโหลดข้อมูลอะไร (ภาพเก็บที่โฟลเดอร์ผลลัพธ์ → `_error_dialogs`) แก้ข้อมูลแล้วกด
**ประมวลผลซ้ำปีที่มีปัญหา** ในกล่องเดียวกัน
error ประเภทนี้ส่วนใหญ่เป็น**ปัญหาที่ตัวข้อมูลต้นทาง**ที่ CropWat เองไม่ยอมรับ เช่น
"Rain data (January) are not OK" = ไฟล์ rain ของสถานะนั้นมีข้อมูลไม่ครบ/ผิดรูปแบบ
ในเดือนที่ระบุ ต้องแก้ที่ไฟล์ข้อมูล ไม่ใช่ที่โปรแกรม (โฟลเดอร์ `_error_dialogs`
ลบทิ้งได้เสมอ ไม่เกี่ยวกับไฟล์ส่งงาน)

**เปิดโปรแกรมแล้วค้างที่ "กำลังเชื่อมต่อ..."**
ปิดหน้าต่างโปรแกรม แล้วดับเบิลคลิกไอคอนโปรแกรมเปิดใหม่อีกครั้ง — ถ้ายังไม่หาย

## 10. การอัปเดตโปรแกรม

- โปรแกรมตรวจเวอร์ชันใหม่ให้อัตโนมัติ (ต้องต่ออินเทอร์เน็ต) มีใหม่จะเด้งแจ้งใน
  โปรแกรม กด **อัปเดตทันที** ได้เลย — ดาวน์โหลดเสร็จโปรแกรมปิด-เปิดใหม่เอง
- กดตรวจเองได้ที่ปุ่ม **↻** (ตรวจอัปเดต) มุมขวาบน
- ⚠ **อย่าอัปเดตระหว่างกำลังประมวลผล** — งานรอบนั้นจะหยุดกลางคัน (ข้อมูลที่เสร็จ
  แล้วไม่หาย เริ่มต่อจากเดิมได้ แต่เสียเวลารอบใหม่) รอให้งานเสร็จก่อนค่อยอัปเดต
